# First-paper major revision record — 28 September 2026

For Salma's revision record: the comments identified a conceptual error in which a liquidated position was charged its full hypothetical final-horizon repayment and a liquidation penalty. I replaced that result with two mutually exclusive conditional ledgers. The previously published scenario-weighted risk-adjusted medians and associated result CSV, tables and figures were withdrawn from the current branch. See documentation/RESPONSE_TO_SALMA.md for a comment-by-comment account.

The revised manuscript measures *FX-driven* rather than inflation-driven debt erosion. It leads with the selected 7,105 clean repaid spells per currency (median 6.95 days), then distinguishes imposed fixed-horizon scenarios. The code reports urn counts, first-draw and per-urn aggregates, amount-weighted concentration by draw size and origination month, size thresholds, duration bands and a generic terminal collateral-ratio screen. Fee timing, rate convention, conversion steps and gas transactions are explicit. The framework separates performing loan assets, settled recovery, issuer reserves, token liabilities and asset write-downs; no actual protocol-solvency estimate is claimed.

Primary reproducibility entry point: bash run_all.sh. Numeric source map: documentation/RESULTS_VALIDATION.md. Assumption provenance: documentation/PARAMETER_PROVENANCE.csv. The original Git history preserves superseded outputs for audit; the working revision contains only the corrected current results.
