# First-paper major revision record — 28 September 2026

For Salma's revision record: the comments identified a conceptual error in which a liquidated position was charged its full hypothetical final-horizon repayment and a liquidation penalty. I replaced that result with two mutually exclusive conditional ledgers. The previously published scenario-weighted risk-adjusted medians and associated result CSV, tables and figures were withdrawn from the current branch. See documentation/RESPONSE_TO_SALMA.md for a comment-by-comment account.

The revised manuscript measures *FX-driven* rather than inflation-driven debt erosion. It leads with the selected 7,105 clean repaid spells per currency (median 6.95 days), then distinguishes imposed fixed-horizon scenarios. The code reports urn counts, first-draw and per-urn aggregates, amount-weighted concentration by draw size and origination month, size thresholds, duration bands and a generic terminal collateral-ratio screen. Fee timing, rate convention, conversion steps and gas transactions are explicit. The framework separates performing loan assets, settled recovery, issuer reserves, token liabilities and asset write-downs; no actual protocol-solvency estimate is claimed.

Primary reproducibility entry point: bash run_all.sh. Numeric source map: documentation/RESULTS_VALIDATION.md. Assumption provenance: documentation/PARAMETER_PROVENANCE.csv. The original Git history preserves superseded outputs for audit; the working revision contains only the corrected current results.

## Subsequent methodological changes

Following four additional methodological comments, the manuscript gives a direct rationale and external-validity limit for MakerDAO as the source of principal sizes and timestamps. The selected observed-duration results now use archived official daily BCRA and ECB reference marks; the prior OECD/FRED monthly result and a same-source monthly mean are retained as explicit comparisons for the identical 7,105 spells. The main text includes a six-rate daily-FX borrowing-cost sensitivity and clarifies that the round 20% baseline is illustrative and official reference FX is not necessarily executable. Detailed terminal collateral screens were moved to an Appendix and the balance-sheet discussion was shortened to its accounting boundary. A full response and output map are in `documentation/COLLEAGUE_COMMENTS_RESPONSE.md` and `documentation/RESULTS_VALIDATION.md`.

## Annotated manuscript and expanded discussion

The subsequent annotated PDF and accompanying three overall comments asked for stronger integration of the sections, critical engagement with existing work, clearer contribution and deeper result interpretation. The introduction, related research, Data and methodology, Discussion and limitations, abstract and conclusion were rewritten accordingly. Newly cited primary research on currency mismatch, exchange-rate balance sheets and currency-denomination selection is included in both bibliography sources. The main text now compares the selected clean spells with all draw events and repeats imposed horizons on the same selected starts, so the 12-month TRY result is no longer attributed to duration alone. Strictly earlier published FX dates, an illustrative accessible-rate wedge, a gas/spread grid and a reconciled weighted cash-flow decomposition are generated from archived inputs. The duplicate duration curve was removed. A detailed response and exact output map are in `documentation/ANNOTATED_MANUSCRIPT_RESPONSE.md` and `documentation/RESULTS_VALIDATION.md`.
